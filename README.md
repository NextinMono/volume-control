# Volume Control
Program to emulate media keys on keyboards that don't have them.
## Usage
RCTRL + F6 = Play/Pause

RCTRL + F9 = Mute

RCTRL + F10 = Volume-

RCTRL + F11 = Volume+

## Why?
I recently switched from a Tecware to a Yunzii keyboard, and this keyboard doesnt have anything for controlling volume or media, so I made this to make it work like the old keyboard I had.
